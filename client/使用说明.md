# 稳卖调研 Agent · 使用说明

## 这是什么

一个部署在**你自己电脑上**的跨境电商数字员工团队。你说出任务，智能体按「数字员工路由表」分派给 8 个员工人设（市场调研员、选品分析师、竞品监控哨兵、广告优化师、打单专员、Listing 工程师、上架专员、图片设计师），调用对应的任务 Skill 执行，覆盖调研、选品、竞品、广告、单证、Listing、上架、图片全流程。

- 模型：你自己的 API Key（DeepSeek / OpenAI / 任意 OpenAI 兼容服务）
- 凭证：全部保存在本机，不上传任何服务器
- 平台：支持绑定「稳卖调研」平台（数据工具 + Skill 市场 + 社区），不绑定也能用
- 未配置 Walmart API 时广告功能自动使用**演示模式**（模拟账户，功能全可试）

## 准备

- Windows 10/11 电脑（安装包已内置 Node 运行时，无需安装）
- 一个模型 API Key（DeepSeek 推荐：https://platform.deepseek.com）
- 可选：稳卖调研平台地址；Walmart Connect API 凭证（直连真实广告账户）

## 首次使用（约 2 分钟）

1. 双击 `启动.bat`，自动进入配置向导；
2. 配置模型：选提供商 → 粘贴 API Key；
3. 数据服务：有邀请码选「邀请码注册」（自动获取数据 API Key 并接入），没有可暂不接入；
4. 平台协议：直接回车用默认地址，稍后在会话里说「绑定平台」完成配对；
5. Walmart Connect：选「演示模式」先体验，或选「直连模式」粘贴 API 凭证；
6. 再次双击 `启动.bat` —— 首次启动约 1 分钟，之后浏览器自动打开。

> 浏览器没自动打开时，在启动窗口找形如 `http://127.0.0.1:3220/?token=...` 的链接手动打开。

## L2 审批纪律

上架类与报关单类任务是**写操作**：智能体会先汇总将要发布/生成的完整内容，取得你明确批准后才执行；广告预算、出价等写操作同样先给方案等确认。

## 常见问题

**问：怎么绑定稳卖调研平台？**
会话里说「绑定平台」，智能体调用 wm_bind 完成配对（平台地址可在 `wenmai-config.json` 的 `platform_url` 修改）。绑定后可用平台数据工具（搜索 / 抓取 / 零售数据）与 Skill 市场。

**问：想从演示模式切换到直连真实广告账户？**
编辑 `wenmai-config.json`，把 `walmart.mode` 改为 `live` 并填入 `client_id / client_secret / consumer_id / key_version / private_key（或 private_key_file）/ advertiser_id`，重启即可。凭证来自 Walmart 卖家后台 API Key 生成页（developer.walmart.com/generateKey）或 WCPN 合作伙伴入驻。

**问：想换模型 / 换 Key？**
编辑 `home\settings.yaml`（模型与地址）和 `home\.credentials.yaml`（Key），重启即可。

**问：数据存在哪里？**
全部在本机：任务产出在 `workspace\`，会话数据在 `home\`，模拟广告状态在 `mock-walmart-state.json`。

**问：换电脑？**
把整个目录拷贝到新电脑即可（含配置）。或删除 `wenmai-config.json` 与 `home\settings.yaml` 后重新走向导，再手动把 Key 填回。
