# 稳卖调研 Agent · 使用说明

## 这是什么

一个部署在**你自己电脑上**的跨境电商数字员工团队。你说出任务，智能体按「数字员工路由表」分派给 7 个员工人设（市场调研员、选品分析师、竞品监控哨兵、打单专员、Listing 工程师、上架专员、图片设计师），调用对应的任务 Skill 执行，覆盖调研、选品、竞品、单证、Listing、上架、图片全流程。

- 模型：邀请码注册后由平台自动下发，无需手动填写；也可用自己的 API Key（DeepSeek / OpenAI / 任意 OpenAI 兼容服务）
- 凭证：全部保存在本机，不上传任何服务器
- 平台：支持绑定「稳卖调研」平台（数据工具 + Skill 市场 + 社区），不绑定也能用

## 准备

- Windows 10/11 电脑（安装包已内置 Node 运行时，无需安装）
- 稳卖调研平台的邀请码（推荐：注册后模型与数据服务自动配置）
- 无邀请码时：一个模型 API Key（DeepSeek 推荐：https://platform.deepseek.com）

## 首次使用（约 2 分钟）

1. 双击 `启动.bat`，自动进入配置向导；
2. 配置模型：有邀请码可全部回车跳过（下一步注册成功后自动写入）；也可手动选提供商粘贴 API Key；
3. 数据服务：有邀请码选「邀请码注册」——账户名 + 邀请码，注册成功自动获取数据 API Key，并自动配置平台下发的模型服务；
4. 再次双击 `启动.bat` —— 首次启动约 1 分钟，之后浏览器自动打开。

> 浏览器没自动打开时，在启动窗口找形如 `http://127.0.0.1:3220/?token=...` 的链接手动打开。

## L2 审批纪律

上架类与报关单类任务是**写操作**：智能体会先汇总将要发布/生成的完整内容，取得你明确批准后才执行。

## 常见问题

**问：怎么绑定稳卖调研平台？**
会话里说「绑定平台」，智能体调用 wm_bind 完成配对（平台地址可在 `wenmai-config.json` 的 `platform_url` 修改）。绑定后可用平台数据工具（搜索 / 抓取 / 零售数据）与 Skill 市场。

**问：想换模型 / 换 Key？**
编辑 `home\settings.yaml`（模型与地址）和 `home\.credentials.yaml`（Key），重启即可。用平台下发的模型服务时无需改动。

**问：数据存在哪里？**
全部在本机：任务产出在 `workspace\`，会话数据在 `home\`。

**问：换电脑？**
把整个目录拷贝到新电脑即可（含配置）。或删除 `wenmai-config.json` 与 `home\settings.yaml` 后重新走向导，再手动把 Key 填回。
