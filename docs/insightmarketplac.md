# insightmarketplac 客户端

**AI 品牌出海调研客户端** — 一句话派活，一次性出完整报告。Home Depot 渠道价格 / 库存 / 容量 / 趋势速览，外加调研、竞品、广告、Listing、利润、促销全流程任务。

> 开箱即用：平台数据服务与模型已预置在安装包内，无需注册、无需配置任何 API Key，安装即用。

## 📥 下载安装（Windows）

1. 打开 [Releases 页面](../../releases)，找到 **insightmarketplac 客户端 v1.0.0**；
2. 下载 `insightmarketplac-Setup-1.0.0-client01.exe`；
3. 双击安装，完成后自动启动，直接进入任务首页。

直达下载：[insightmarketplac-Setup-1.0.0-client01.exe](https://github.com/Hdhaidong/wenmai-agent/releases/download/insightmarketplac-v1.0.0/insightmarketplac-Setup-1.0.0-client01.exe)

## ✨ 能做什么

### 速览（点一下，等几分钟，看完整报告）

| 任务 | 说明 |
|------|------|
| 💲 价格速查 | 竞品现价 / 划线价总表、价格带分布、促销占比、定价卡位建议 |
| 📦 库存速览 | 库存状态核验（有货/缺货/门店限定）、变体差异、缺货补位机会清单 |
| 🌊 容量测算 | 在售规模、评论数反推销量区间（假设明示）、头部集中度、进入空间评级 |
| 📈 趋势速览 | 季节基线定位、热度信号、价格走势信号、未来 60 天动作窗口 |

### 全流程任务

市场调研 / 竞品分析 / 广告投放（赛马冷启动、自动淘汰）/ Listing 生成 / 利润测算 / 促销方案 — 共 17 个任务 Skill。

### 体验特点

- **一次出全文**：报告生成完一次性完整呈现，不逐字刷屏
- **💬 反馈入口**：首页右上角可直接提需求，直达产品团队
- **零配置**：数据服务、模型均已预置；写操作需人工确认才执行
