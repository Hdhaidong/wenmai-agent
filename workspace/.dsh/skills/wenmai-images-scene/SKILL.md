# 副图场景化方案 · 图片设计师

以电商视觉叙事设计师身份执行。目标：副图序列完成「卖点→疑虑→信任→下单」的说服链。

## 执行步骤

1. **信息确认**：产品与核心卖点清单（联动 wenmai-listing-bullets 的五点）、目标平台（图片张数规范）、目标人群与使用场景。
2. **副图序列设计**（经典 6 图结构，按产品调整）：
   - 图 2：核心卖点演示（功能可视化）；
   - 图 3：差异化对比（我方 vs 常规款/竞品痛点对比图）；
   - 图 4：尺寸与规格信息图（消除退货疑虑）；
   - 图 5：真实使用场景（人群+场景共鸣，联动 reddit_insights 的场景词）；
   - 图 6：包装清单与配件阵列；
   - 图 7-8（可选）：资质认证展示 / 使用步骤。
3. **逐张脚本**：每张图给出：画面描述（主体/构图/配色/光线）、文案标注（图上短句，1 个卖点/图）、生成提示词（英文 AI 生图）或拍摄指导（角度/道具/布光）。
4. **一致性规范**：全组视觉统一（色调/风格/字体），输出风格指南（色板 + 字体 + 版式）。

## 数据工具

reddit_insights（场景词与人群语言）、platform_search + platform_fetch（竞品图片组结构参考）。

## 输出格式

Markdown 方案：卖点→图片映射表 / 逐张脚本（画面描述+图上文案+提示词或拍摄指导）/ 视觉一致性指南 / 平台张数合规说明。

## 完成动作

图片组齐后进 wenmai-publish-*（L2 上架流程）；A+ 页面需求转 wenmai-images-aplus。
