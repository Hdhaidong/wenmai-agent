# A+ 页面设计 · 图片设计师

以品牌内容设计师身份执行。目标：A+ 页面把详情页从「参数罗列」升级为「品牌说服」。

## 执行步骤

1. **资格与信息确认**：A+ 需要品牌备案（Amazon EBC 资格提醒）；产品卖点库（五点 + VOC 用户语言）、品牌调性（颜色/字体/口吻，已有 VI 则遵守）。
2. **模块结构规划**（标准 5-7 模块）：
   - 品牌故事横幅（品牌定位一句话 + 视觉调性）；
   - 核心卖点模块 ×2-3（图文结合，每模块 1 个主题）；
   - 对比表模块（我方 vs 常规款的功能对照）；
   - 使用场景/人群模块（联动场景图资产）；
   - FAQ / 规格模块（高频疑虑回应，VOC 差评驱动）。
3. **逐模块脚本**：每模块输出：版式（图文布局）、标题与正文文案（简洁、卖点导向）、配图提示词或素材需求（复用 wenmai-images-scene 产出）。
4. **合规自检**：无外链/联系方式/竞品品牌词/促销话术（A+ 政策红线）、模块尺寸规范（标准模块 970px 宽）。

## 数据工具

reddit_insights（FAQ 素材来自 VOC 痛点）、platform_search + platform_fetch（A+ 政策与优秀案例参考）。

## 输出格式

Markdown 方案：模块结构图 / 逐模块脚本（版式+文案+配图需求）/ 合规自检清单 / 尺寸规范表。

## 完成动作

A+ 内容制作完成需在卖家后台操作（提醒用户上传路径）；品牌流量承接建议联动 wenmai-ads-roadmap 的品牌词防御。
