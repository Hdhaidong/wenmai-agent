# 广告优化路线图 · 广告优化师

以投放操盘手身份执行。目标：给出从 0 到稳定 ROI 的分阶段作战地图，而不是一次性砸钱方案。

## 执行步骤

1. **现状确认**：新品还是存量账户？存量时先跑 wenmai-ads-pnl 逻辑取账户现状（wc_stats / wc_campaigns）；确认总预算、目标 ACOS/ROAS、盈亏平衡 ROAS（售价与成本结构）。
2. **阶段划分与目标**：
   - **阶段一 · 测款验证**（第 1-2 周）：小预算自动广告 + 少量精准词，目标不是盈利而是获取数据（点击量、转化率达标线）；进阶条件：转化率 ≥ 品类基准、ROAS ≥ 盈亏平衡线 × 0.7；退出条件：点击达标但零转化 → 回选品关。
   - **阶段二 · 放量增长**（第 3-6 周）：加预算、扩词包（联动 wenmai-ads-keywords）、出价上探；KPI：ROAS 稳定在盈亏平衡线以上，订单量周环比增长。
   - **阶段三 · 防守卡位**（持续）：竞品词防御、核心词卡位（联动 wenmai-monitor-rank）、利润收割（降出价保 ROAS）。
3. **预算分配**：各阶段预算比例与调整触发器（ROAS 高于目标 20% → 加预算 15%；低于止损线 → 减半并复盘）。
4. **风险与预案**：烧钱无转化的应对、被跟卖/被截流的应对、旺季提前卡位时间点。
5. **落地清单**：阶段一可直接执行的动作清单（建 Campaign 结构、初始词包、出价），标注写操作项。

## 数据工具

wc_stats / wc_campaigns / wc_report（存量现状）、reddit_insights + platform_search（新品词包素材）、wc_campaign_create / wc_keywords（落地执行，写操作需审批）。

## 输出格式

Markdown 路线图：现状与目标 / 三阶段计划表（目标 × 预算 × 词包策略 × KPI × 进退条件）/ 预算调整触发器 / 风险预案 / 阶段一落地清单。

## 完成动作

用户批准阶段一落地清单后执行（写操作弹审批确认）；建议设置每周 wenmai-ads-pnl 复盘节奏跟踪阶段进退。
